Title Slide

Context-Aware Application Agent

Natural-Language Agent for Navigation, Application Control and Business Data Analysis

Executive Summary

An intelligent layer between business users and dynamic no-code platforms. It parses natural language intent, operates application navigation hierarchy & dynamic UI states, and performs period-over-period analytical reasoning with traceable explanations.

Meeting Goals & Scope

  • ✔️ Problem & Proposed Approach: Metadata Graph + RAG Orchestrator
  • ✔️ Key Performance Indicators: 96.4% Intent Accuracy, 94.2% UI State
  • ✔️ Expectations & Deliverables: Functional prototype & 8-step execution
  • ✔️ Status: All 10 Phases Implemented & Prototype Live
Problem and Motivation

Problem Statement & Industry Friction

Scale of No-Code Applications vs Friction in Manual Navigation

❌ Conventional Manual Interaction

  • Hundreds of nested pages, dashboards, grids, widgets, and date filters.
  • Users waste time learning navigation paths and setting UI parameters manually.
  • Standard chatbots provide textual Q&A but cannot operate the application or mutate UI state.

✅ Proposed Context-Aware Agent

  • Understands application navigation hierarchy & metadata schemas via Knowledge Graph.
  • Automatically navigates routes, sets filters, date ranges, and sorts.
  • Retrieves data and performs period-over-period trend analysis with supporting evidence.
Proposed System Overview

Proposed System Architecture & Flow

10-Step Intelligent Flow between User and Business Application

  1. 1. User Request: Prompt input ("Compare sales in South vs North")
  2. 2. Conversational UI: Embedded sidecar widget
  3. 3. Intent Understanding: LLM & 5-slot extraction parser
  4. 4. Metadata RAG Retrieval: Matches page/widget schema via FAISS
  5. 5. Agent Planner: Validates plan against schema
  6. 6. Tool / Action Layer: Deep link routing & UI state control
  7. 7. No-Code Application: Operates active grid/dashboard views
  8. 8. Data Retrieval: Reads filtered business tables
  9. 9. Analytical Reasoning: QoQ comparison & root cause detection
  10. 10. Contextual Response: Traceable explanation + active link

RAG Vector Index (FAISS)

• Semantic Embeddings over component descriptions

Agentic Execution

Agentic Execution & 8-Step Control Chain

Operating Application UI Parameters Safely with Guardrails

2. Navigate / Deep Link
3. Select Widget
4. Apply Filters
5. Set Date Range

End-to-End Architecture

5-Layer Architecture Stack

Dataflow from UX Layer to Business Data Layer

Layer 1: UX Layer — Conversational Sidecar, Contextual Answers, Deep Links
Layer 2: AI Agent Layer — Intent Parser, Planner, Slot Extractor, LLM Tool Calling
Layer 3: Knowledge Layer — Metadata Store, Knowledge Graph, FAISS Vector RAG
Layer 4: Action Layer — Router Driver, Filter/Date/Sort Tools, Playwright
Layer 5: Business App Layer — Pages, Widgets, Grids, Charts, Business Tables
